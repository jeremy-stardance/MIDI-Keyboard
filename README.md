## MIDI Keyboard Project

This is for week 3 of Hack Club Half-Life

![Image](https://github.com/jeremy-stardance/MIDI-Keyboard/blob/main/Images/Screenshot%202026-10-20%20150213.png)

This is my schematic for eight buttons, run on an Arduino Pro Micro. It should allow me to create an output of notes C through to C.

## Bill Of Materials

| Component | Quantity | Cost ($) |
|---|---:|---:|
| Arduino Pro Micro | 1 | 9.33 |
| Breadboard | 1 | 8.85 |
| Jumper Wire | 130 | 7.92 |

The prices are in $USD. I am using the Arduino Pro Micro as a 'brain' for the project. The wires will be used to jump across my PCB Development Board, and I will use the breadboard to test code and wiring because I am not confident enough in my code to want to just hope for the best.

I already own a PCB Development Board, and 8 Buttons, so didn't need to but them on the BOM.

## What I Have Learnt

Before this, I had only used arduino templates as code, but this is the first time I actually tweaked and changed code. I had to learn a little bit of the coding language (with help from AI). 

Also, I had to learn to find my own schematic files and footprints, rather than have them given to me like in the Starbie project using the tutorial. This took some time.

## Why a MIDI Keyboard

I play piano as a hobby. I thought that a MIDI Keyboard would be a cool devise to be able to have, even though it will not have any sharps or flats.
